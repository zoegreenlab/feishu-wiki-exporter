# 使用说明

## 文件边界

data/storage_state.json is browser login state. data/network_log.json and
data/full_wiki_tree.json are generated local metadata. output/ contains exported
content and failure logs. All are ignored by Git and must remain local.

## 常见问题

### 找不到登录状态

执行 login，在浏览器完成登录后回到终端按 Enter。

### build-tree 找不到目录请求

重新对目标 Wiki 首页执行 capture-network，再执行 build-tree。

### 找不到 feishu-docx

确认 feishu-docx --help 能在当前终端运行。

### 个别页面导出失败

查看 output/export_failures_browser.jsonl。该日志可能包含页面 URL，仅应保存在本地。
